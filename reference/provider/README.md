# Reference Provider

Next.js service implementing the Provider side of the
[specification](../../docs/spec.md) (Identity profile): per-Brand Agent Cards,
PA JWT verification, `message:send` with `contextId` continuation, task
routes, and self-service PA registration. Brand agents are scripted demos
(optionally OpenAI-backed). The code calls Brands `customers`.

Setup, environment, data model, deployment:
[Run the reference stack](../../docs/running.md#run-it-locally).
