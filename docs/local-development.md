# Local development

## Prerequisites

Use Node.js 20 or later, pnpm 11.21.0, and the dependencies declared by the
workspace.

```sh
pnpm install
pnpm gen-keys
```

`pnpm gen-keys` prepares a local ES256 key pair: the JWKS server exposes the
public key, and the PA client uses the private JWK from its ignored
`.env.local`. Keep the private JWK out of source control.

## Start the database and apps

Start these four processes in separate terminals:

```sh
pnpm --filter @pac2/personal-agent-server dev
PGLITE_DATA_DIR="$HOME/.local/share/pac2-provider-db" pnpm --filter @pac2/provider db:pglite
pnpm --filter @pac2/provider dev
pnpm --filter @pac2/personal-agent-client dev
```

They listen on ports 3002, 5432, 3000, and 3001 respectively. PGlite uses a
persistent directory at `~/.local/share/pac2-provider-db` by default.

Initialize a fresh database after PGlite is ready:

```sh
export DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5432/postgres
export DATABASE_POOL_MAX=1
export PA_ISSUER=http://localhost:3002
pnpm --filter @pac2/provider db:migrate
pnpm --filter @pac2/provider db:seed
```

Seeding prints `Acme Health id: …` and `Globex Clinic id: …`. It creates the
`demo-pa` platform enabled and `disabled-pa` disabled. Set
`SEED_DEMO_PLATFORM=false` for the seed command to omit `demo-pa` and try
self-service registration; `disabled-pa` remains seeded. See the
[provider README](../apps/provider/README.md) for the schema and environment.

Set these values in `apps/personal-agent/client/.env.local`:

```dotenv
PROVIDER_URL=http://localhost:3000
CUSTOMER_ID=<Acme Health ID printed by the seed>
PA_ISSUER=http://localhost:3002
PA_PLATFORM_NAME=demo-pa
PA_PRIVATE_JWK=<private JWK generated by pnpm gen-keys>
```

`PA_AUDIENCE` is optional; leave it unset for the shared default audience.
Open `http://localhost:3001` after the client is running. The client requires
the PA issuer and private JWK for signing and registration.

For a local PostgreSQL server instead of PGlite, set `DATABASE_URL` to that
database and run the same migration and seed commands.

## Checks

Run the workspace checks and builds from the repository root:

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm format:check
pnpm --filter @pac2/provider build
pnpm --filter @pac2/personal-agent-client build
pnpm e2e
```

The E2E suite uses the running local JWKS and provider services. Supply
`PROVIDER_URL`, `CUSTOMER_ID`, `GLOBEX_ID`, and `PA_ISSUER`; it reads
`PA_PRIVATE_JWK` from the environment or the PA client `.env.local`. See the
[E2E README](../e2e/README.md) for its coverage. See the
[operations reference](../apps/docs/content/reference/operations.md),
[authentication guide](../apps/docs/content/guides/authentication.md), and
[errors reference](../apps/docs/content/reference/errors.md) for request,
audience, and error details.
